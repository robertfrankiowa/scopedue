Restore ScopeDue as New Tab

If new tabs no longer show ScopeDue, follow these steps:

  1. Open Extensions and turn off other extensions that replace New Tab.
  2. If needed, turn ScopeDue off and back on. Accept the browser confirmation to keep ScopeDue as New Tab if it appears.
  3. Return to this panel and open a new tab to check.

The browser requires you to make this change. Private windows keep the browser's own New Tab.
